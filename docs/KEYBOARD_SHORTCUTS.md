# 3T Reader — Keyboard Shortcuts

## File Operations

| Shortcut | Action |
|----------|--------|
| `Ctrl+O` | Open file |
| `Ctrl+S` | Save |
| `Ctrl+Shift+S` | Save As |
| `Ctrl+N` | New blank PDF |
| `Ctrl+W` | Close current tab |
| `Ctrl+P` | Print |

## Navigation

| Shortcut | Action |
|----------|--------|
| `Left` | Previous page |
| `Right` | Next page |
| `Home` | First page |
| `End` | Last page |
| `Ctrl+G` | Go to page |

## View

| Shortcut | Action |
|----------|--------|
| `Ctrl++` | Zoom in |
| `Ctrl+-` | Zoom out |
| `Ctrl+0` | Fit page |
| `F11` | Fullscreen |
| `Ctrl+Shift+D` | Toggle dark/light theme |

## Edit & Annotations

| Shortcut | Action |
|----------|--------|
| `Ctrl+H` | Highlight mode |
| `Ctrl+Z` | Undo |
| `Delete` | Delete selected object |
| `Escape` | Cancel current operation |

## Search

| Shortcut | Action |
|----------|--------|
| `Ctrl+F` | Find in document |
| `F3` | Find next |
| `Shift+F3` | Find previous |

## Signing

| Shortcut | Action |
|----------|--------|
| `Ctrl+Shift+K` | Open signing dialog |

## General

| Shortcut | Action |
|----------|--------|
| `F1` | Help / About |
| `Ctrl+Q` | Quit |
